# ଅଧ୍ୟାୟ ୨: ଦୈନନ୍ଦିନ ଆବଶ୍ୟକ ଶବ୍ଦାବଳୀ (Essential Vocabulary)

ସୁଗମ ଭାବେ କଥାବାର୍ତ୍ତା କରିବା ପାଇଁ ଶବ୍ଦଭଣ୍ଡାର (Vocabulary) ଅତ୍ୟନ୍ତ ଆବଶ୍ୟକ। ଏହି ଅଧ୍ୟାୟରେ ଦୈନନ୍ଦିନ ବ୍ୟବହୃତ ମୁଖ୍ୟ ଶବ୍ଦଗୁଡ଼ିକ ପ୍ରଦାନ କରାଯାଇଛି।

---

## ୧. ଶିଷ୍ଟାଚାର ଓ ଅଭିବାଦନ (Greetings & Courtesy)

| ଓଡ଼ିଆ ଶବ୍ଦ (Odia) | ଉଚ୍ଚାରଣ (Transliteration) | ଇଂରାଜୀ ଅର୍ଥ (English) |
| :--- | :--- | :--- |
| **ନମସ୍କାର** | Namaskāra | Hello / Greetings |
| **ଶୁଭ ସକାଳ** | Śubha sakāḷa | Good morning |
| **ଶୁଭ ରାତ୍ରି** | Śubha rātri | Good night |
| **ଧନ୍ୟବାଦ** | Dhanyabāda | Thank you |
| **ଦୟାକରି** | Dayākari | Please |
| **କ୍ଷମା କରନ୍ତୁ** | Kṣamā karantu | Excuse me / Sorry |
| **ହଁ** | Hām̐ | Yes |
| **ନା / ନାହିଁ** | Nā / Nāhīm̐ | No / Not |
| **ଆଜ୍ଞା** | Ājñā | Yes (respectful affirmative) |
| **ପୁଣି ଦେଖାହେବ** | Puṇi dekhāheba | See you again |

## ୨. ସର୍ବନାମ (Pronouns)

| ଓଡ଼ିଆ ଶବ୍ଦ (Odia) | ଉଚ୍ଚାରଣ (Transliteration) | ଇଂରାଜୀ ଅର୍ଥ (English) | ବ୍ୟବହାର ଟିପ୍ପଣୀ (Usage Note) |
| :--- | :--- | :--- | :--- |
| **ମୁଁ** | Mum̐ | I | ପ୍ରଥମ ପୁରୁଷ (First person) |
| **ଆମେ / ଆମ୍ଭେମାନେ** | Āme / Āmbhemāne | We | ବହୁବଚନ (Plural) |
| **ତୁ** | Tu | You (intimate/younger) | ସାଙ୍ଗ ବା ସାନମାନଙ୍କ ପାଇଁ |
| **ତୁମେ** | Tume | You (informal/peers) | ସମବୟସ୍କଙ୍କ ପାଇଁ |
| **ଆପଣ** | Āpaṇa | You (formal/respectful) | ବୟୋଜ୍ୟେଷ୍ଠ ଓ ସମ୍ମାନନୀୟ ବ୍ୟକ୍ତି |
| **ସେ** | Se | He / She | ତୃତୀୟ ପୁରୁଷ (Third person) |
| **ଏ / ଏହା** | E / Ehā | This | ନିକଟବର୍ତ୍ତୀ ବସ୍ତୁ ବା ବ୍ୟକ୍ତି |
| **ସେହି / ତାହା** | Sehi / Tāhā | That | ଦୂରବର୍ତ୍ତୀ ବସ୍ତୁ |

## ୫. ରଙ୍ଗ (Colors)

- **ଧଳା** (Dhaḷā) - White
- **କଳା** (Kaḷā) - Black
- **ନାଲି / ଲାଲ୍** (Nāli / Lāl) - Red
- **ହଳଦିଆ** (Haḷadiā) - Yellow
- **ନୀଳ** (Nīḷa) - Blue
- **ଶାଗୁଆ / ସବୁଜ** (Śāguā / Sabuja) - Green
- **କମଳା** (Kamaḷā) - Orange

## ୬. ସପ୍ତାହର ବାର (Days of the Week)

1. **ରବିବାର** (Rabibāra) - Sunday
2. **ସୋମବାର** (Somabāra) - Monday
3. **ମଙ୍ଗଳବାର** (Maṅgaḷabāra) - Tuesday
4. **ବୁଧବାର** (Budhabāra) - Wednesday
5. **ଗୁରୁବାର** (Gurubāra) - Thursday
6. **ଶୁକ୍ରବାର** (Śukrabāra) - Friday
7. **ଶନିବାର** (Śanibāra) - Saturday
